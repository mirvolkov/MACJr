# 3. A tiny radio

The receiver is a Tayloe detector: a fast switch that mixes the antenna
signal down to audio. It needs a local oscillator at the receive frequency,
in two copies 90 degrees apart, one for I and one for Q. We generate it
with an Si5351 clock chip that sits on the same I2C bus as the keyboard.

## Sharing the bus

Two drivers now needed one I2C bus, so the bus moved into its own small
component. `i2c_bus_get()` creates the bus on first use and hands the same
handle to everyone after that. Our first version guarded that creation
with a lock written as a temporary value, which protects nothing because
each call got a fresh lock. The fix was a single static lock.

## The Si5351, from the datasheet

We did not want a third-party library, so the driver follows Skyworks
application note AN619 directly. The chip multiplies its 25 MHz crystal up
to 600-900 MHz (a PLL), then divides it down for each output. For a clean
90-degree shift, the divider must be an even whole number of at most 126.
For 7.055 MHz:

```
N   = 126                         even, at most 126
PLL = 7.055 MHz x 126 = 888.93 MHz   inside 600-900 MHz
PLL / 25 MHz = 35.557...          written as a + b/c
```

Each value is packed into the chip's registers with AN619's formulas:

```c
P1 = 128 * a + floor(128 * b / c) - 512;
P2 = 128 * b - c * floor(128 * b / c);
P3 = c;
```

The quadrature trick is the phase-offset register: setting CLK1's offset to
N delays it by a quarter of a period. It only takes effect after a PLL
reset, so the sequence ends with a reset and then enables the outputs:

```c
write_reg(166, n);        /* CLK1 phase offset = N -> 90 degrees */
write_reg(177, 0x20);     /* reset PLL A: apply the phase */
write_reg(3, ~0x03);      /* enable CLK0 and CLK1 */
```

**Result:** an `sdr` component with `sdr_init()` and
`sdr_set_freq(hz)` that covers 4.762 to 150 MHz, started from the boot
menu along with USB audio. The I/Q outputs still need checking on a scope
and with a real antenna.
