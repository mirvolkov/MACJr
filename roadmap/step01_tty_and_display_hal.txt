Step 01 — TTY subsystem + display HAL
Date: 2026-06-24
Goal: Full hardware bring-up; text output to physical LCD via a unix-style TTY layer.

===========================================================================
WHAT WAS BUILT
===========================================================================

1. components/macjr_tty/  — core TTY component (ESP-IDF component)

   tty.c / tty.h
     - macjr_tty_t: opaque handle tying a virtual console to a display HAL
     - macjr_tty_create(hal, glyph_w, glyph_h) — allocates VC sized to fit panel
     - macjr_tty_read / macjr_tty_write — unix-style byte-stream API
     - macjr_kbd_inject(tty, data, len) — feed raw keyboard bytes (task-safe)
     - macjr_display_flush(tty) — push dirty cells to the panel (call at frame rate)
     - macjr_tty_vc / _termios / _winsize — inspect internal state

   vc.c / vc.h
     - macjr_vc_t: 2-D cell grid (ch + attrs per cell), cursor position
     - Handles writing characters, advancing cursor, CR/LF, wrapping

   ldisc_ntty.c
     - Line discipline: ICANON + ECHO mode
     - Buffered line input; echoes typed chars back through the TTY write path
     - macjr_kbd_inject drives it; completed lines become available to tty_read

   hal_display.h
     - macjr_hal_display_t: abstract display interface (width, height, blit callback)
     - Board-specific implementations plug in here

   hal_blit.c / hal_blit.h
     - Renders dirty VC cells → pixel rectangles via the HAL blit callback
     - Uses the built-in 8×16 font; only redraws changed cells (dirty tracking)

   font_builtin.c
     - 8×16 monochrome bitmap font
     - Chars 0x20–0x7E: standard printable ASCII
     - Chars 0x80–0xFF: pseudographics page — box-drawing, block shades, arrows,
       geometric shapes, card suits

   termios.h
     - Minimal termios-compatible structs/flags for the line discipline

2. main/  — board-specific glue + demo

   lcd.c / lcd.h
     - Low-level ST7789 LCD driver (SPI, reset, init sequence, pixel write)

   display_hal.c / display_hal.h
     - Implements macjr_hal_display_t for the ST7789 panel
     - display_hal_init() → returns HAL pointer (static storage)

   MACJr.c  — demo / smoke test
     - Inits display HAL → creates TTY
     - Writes ANSI SGR color banner ("MACJr TTY demo", green/red/bold-blue)
     - Injects simulated keyboard input ("root\n") through line discipline
     - Flushes display; reads completed line back and logs it
     - Dumps VC cell grid to ESP log (dump_vc)
     - Renders pseudographics page as a bordered 16×8 grid (dump_pseudographics)
     - Enters 24fps uptime counter loop using ANSI cursor-position escape

3. sdkconfig.defaults  — board config for ESP32-S3-WROOM-1 N16R8
     - Target: esp32s3
     - 16 MB Quad-SPI flash
     - 8 MB Octal PSRAM @ 80 MHz (SPIRAM_MODE_OCT, SPIRAM_USE_MALLOC)

===========================================================================
HOW IT WORKS (DATA FLOW)
===========================================================================

  macjr_tty_write(bytes)
      → ANSI escape parser (inside tty.c/vc.c)
      → updates macjr_vc_t cell grid + cursor
      → marks cells dirty

  macjr_kbd_inject(bytes)
      → line discipline (ldisc_ntty.c)
      → ECHO: feeds echoed chars back through tty_write path
      → ICANON: buffers until \n; completed line queued for tty_read

  macjr_display_flush(tty)
      → hal_blit scans dirty cells
      → for each dirty cell: looks up glyph in font_builtin, calls hal->blit()
      → display_hal blit: SPI-transfers pixel rect to ST7789
      → clears dirty flags

===========================================================================
ANSI FEATURES IMPLEMENTED
===========================================================================
  - SGR colors (foreground/background, bold, reset)
  - Cursor positioning: ESC[row;colH
  - Erase to end of line: ESC[K
